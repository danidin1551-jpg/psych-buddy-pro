# חיבור האפליקציה לקלוד (שרת MCP ציבורי)

הופכים את אפליקציית התרגול לשרת MCP שקלוד (וכל לקוח AI אחר) יכול להתחבר אליו ולהשתמש בכלים שלה.

## מה ייבנה

שרת MCP בשם "Psychometric Practice Pal" בכתובת `/mcp` של האפליקציה, ללא התחברות, עם הכלים הבאים — כולם מבוססים על מחוללי השאלות הקיימים ב־`src/lib/psychomath/generators.ts`:

1. **generate_question** — מייצר שאלת תרגול לפי נושא (חשבון, אחוזים, יחסים, גיאומטריה וכו') ורמת קושי 1-10, ומחזיר את השאלה בלי התשובה.
2. **generate_practice_set** — מייצר סט של מספר שאלות (למשל 5 או 10) לסשן תרגול.
3. **check_answer** — מקבל שאלה ותשובה ומחזיר האם נכון, כולל התשובה הנכונה וההסבר/דרך הפתרון אם קיים.
4. **list_topics** — מחזיר את רשימת הנושאים הזמינים ואת שלבי עץ המיומנויות, כדי שקלוד תדע מה אפשר לבקש.

## גישה ופרטיות

השרת יהיה **ציבורי — בלי התחברות**: כל מי שיש לו את הקישור יכול להפעיל את הכלים. זה בטוח כאן כי הכלים רק מחוללים שאלות ובודקים תשובות — אין מסד נתונים, אין משתמשים, וההתקדמות האישית נשמרת רק בדפדפן שלך ולא נחשפת דרך ה־MCP.

## פרטים טכניים

- התקנת `@lovable.dev/mcp-js` (כבר מאושר ב־`bunfig.toml`) ו־`zod`.
- קבצי כלים חדשים תחת `src/lib/mcp/tools/`, ורישום ב־`src/lib/mcp/index.ts` עם `defineMcp` (ללא `auth`).
- הוספת `mcpPlugin()` ל־`vite.config.ts`; הנתיבים עצמם נוצרים אוטומטית ולא נכתבים ידנית.
- הכלים ייבאו את הלוגיקה הקיימת מ־`generators.ts` / `skillTree.ts` — בלי לשכפל לוגיקה ובלי לגעת ב־UI הקיים.
- הוספת favicon בסיסי אם אין, כדי שהקונקטור יוצג עם אייקון.
- הרצת בדיקת המניפסט בסיום.

## אחרי הבנייה

צריך לפרסם (Publish) את האפליקציה, ואז להעתיק את קישור ה־MCP מ־**More > Agent integrations** ולהוסיף אותו בקלוד כ־custom connector.
